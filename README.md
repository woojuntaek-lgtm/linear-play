# 직선 놀이터

수식 거의 없이 손으로 배우는 선형대수 첫걸음. "직선으로 된 방정식에서 답이 정확히 두 개인 경우는 왜 없을까?"라는 질문 하나를 따라가며, 선형·비선형 구분, 두 직선의 만남, 카페 영수증 연립방정식, 취향을 점(벡터)으로 바꾸는 발상과 AI의 "곱해서 더하기"까지 초심자가 직접 만져 보는 앱입니다. 선형대수 01 부록이며, 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

## 구성
- ① 선형: 두 배 실험(커피값 · 정사각형 넓이 · 제동거리), 세 가지 기준과 선형/비선형 퀴즈 8문항(12문항 중 무작위)
- ② 두 직선: 식 두 개의 숫자를 바꾸면 직선이 움직이며 "하나 / 없음 / 무수히 많음" 판정, 카페 영수증 예시 3종, "왜 딱 2개는 없을까" 설명
- ③ 영수증: 아메리카노·라떼·케이크 가격 맞히기 퍼즐(영수증 3장 실시간 채점, 단계별 힌트)
- ④ 취향 점: 영화 취향 점수 → 2차원 지도와 가장 가까운 친구 추천, 장바구니 벡터 더하기·늘리기, 입력×가중치 곱해서 더하기, 세 줄 정리
